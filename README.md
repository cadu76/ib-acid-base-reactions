# IB DP Chemistry: Acid-Base Equilibrium & Titration Sandbox

An interactive, web-based laboratory simulation designed for **Grade 12 IB Diploma Programme Chemistry** students and educators.

🔗 **Live Interactive Demo:** [https://cadu76.github.io/ib-acid-base-reactions/](https://cadu76.github.io/ib-acid-base-reactions/)

---

## Features

- **4 Titration Systems Supported:**
  - Strong Acid + Strong Base ($\text{HCl} + \text{NaOH}$)
  - Strong Acid + Weak Base ($\text{HCl} + \text{NH}_3$)
  - Weak Acid + Strong Base ($\text{CH}_3\text{COOH} + \text{NaOH}$)
  - Weak Acid + Weak Base ($\text{CH}_3\text{COOH} + \text{NH}_3$)
- **Thermodynamic Chemistry Engine:** Exact charge-balance numerical bisection solver for pH across all concentrations, buffer regions, and salt hydrolysis states.
- **Dual-Mode Analytical Curves:** Real-time dynamic plotting for both **pH Curves** and **Electrical Conductivity Curves**.
- **Interactive Laboratory Glassware:** Visual buret with drip animations, liquid level changes, and color-changing solution based on selected chemical indicators (Phenolphthalein, Methyl Orange, Bromothymol Blue).
- **Active Conductivity Lightbulb:** Visual representation of ionic conductivity based on ion concentrations and ionic mobilities ($\text{H}^+, \text{OH}^-, \text{Na}^+, \text{Cl}^-$, etc.).
- **Sub-Microscopic Molecular View:** Interactive Canvas particle sandbox illustrating ions, molecules, and neutralization collisions in real time.
- **Syllabus Theory & Checkpoint Quiz:** Key definitions, Henderson-Hasselbalch equations, equivalence vs. half-equivalence concepts, and a 5-question exam checkpoint with detailed explanations.
